# N/NPC 核心品牌文件

> 本文件是 N/NPC 官網、簡報、提案、服務設計與對外文案的品牌定位依據。

## 1. 核心定位

### 中文定位

**智慧營運與企業 AI**

### 英文定位

**Smart Operations & Enterprise AI Consulting**

### 核心承諾

**讓營運被看見，讓資料轉化為可以執行的決策。**

### 公司一句話介紹

N/NPC 是協助企業建立智慧營運與企業 AI 能力的系統整合及顧問公司，連接現場、設備、人員、流程、資料與管理決策。

## 2. 品牌定位原則

- 「智慧營運與企業 AI」是 N/NPC 的母定位。
- 「智慧空間」是旗下能力，不是公司的最高層定位。
- OEE 是營運診斷工具之一，不代表整家公司。
- N/NPC 不只導入單一產品，而是協助客戶連接營運活動、數位系統與決策流程。
- 對外溝通應先描述客戶的營運問題與成果，再介紹適合的技術或產品。

第一層提供客戶現在容易理解、採購與落地的解決方案。

- MES

## 4. 第二層：數位營運空間

### 定位

**數位營運空間**是 N/NPC 的策略願景，不是目前與 MES、AI 或 RTLS 並列的單一標準產品。

建議英文名稱：**Digital Operations Environment**

### 概念

N/NPC 協助客戶將設備、人員、資產、流程、身份、位置與即時事件建立成共用數位底座。不同應用不必各自重建感測、定位、資料與身份基礎設施，而能在一致的治理規則下接入營運環境。

### 商業延伸

完成數位底座後，場域業主可從「購買及使用數位系統」進一步成為「經營數位營運平台」的角色：

- 向第三方應用商收取平台接入費。
- 依 API、即時事件或共用基礎設施的使用方式收取服務費。
- 在具備明確權利、資安與資料治理的前提下，建立可持續發展的應用生態。

### N/NPC 的角色

- 數位營運空間架構設計
- 現場系統與企業系統整合
- 身份、位置、設備與事件資料的連接
- API 與第三方應用接入規範
- 資料治理、權限、資安與服務管理設計
- 應用生態與平台商業模式顧問

## 5. 對外溝通架構

### 第一階段：解決營運問題

先協助客戶處理等待與停機、流程耗時、品質不穩、設備異常、找人找物、資料不透明及資產使用率低等問題。

### 第二階段：建立共用數位能力

將設備、人員、資產、流程與事件轉化為可連接、可管理、可衡量的數位營運能力。

### 第三階段：發展平台與收入

讓合格的第三方應用商付費接入共用數位底座，協助場域業主發展平台服務與新的收入來源。

## 6. 建議品牌訊息

### 首頁核心訊息

**讓營運被看見，把浪費變成利潤，把數位能力變成新收入。**

首頁應讓訪客第一眼理解 N/NPC 的商業成果路徑：

1. 看見營運
2. 減少浪費與成本
3. 釋放產能與資產價值
4. 發展數位服務與新收入

### 輔助說明

N/NPC 整合營運系統、現場資料、企業 AI 與空間智能，協助企業降低等待與浪費、提升資產使用率，並建立持續改善的營運能力。

### 數位營運空間願景

**不只導入數位工具，更讓企業擁有可以持續接入應用、創造服務與發展收入的數位營運空間。**

## 7. 用語與承諾邊界

- 不使用「每平方米固定創造多少收入」等缺乏客戶資料支持的承諾。
- 不保證固定節省金額、投資報酬率或新增收入。
- 價值估算必須清楚列出人員、設備、流程、時間、資產與使用情境等假設。
- 不將商業模式描述為出售個人資料。
- 平台收入應來自合規的接入、API、基礎設施或數位服務。
- 所有第三方接入必須納入資料權利、個資、資安、權限與服務品質管理。

3. **策略願景：**數位營運空間
4. **長期價值：**從改善營運，走向建立平台能力與新的數位服務收入
